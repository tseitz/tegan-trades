# Phase 2.1 — Extraction Hardening (asset provenance)

> Combined design + tasks. Ephemeral working doc (gitignored). Intent-level — I execute
> inline/supervised, so this states goal + units + gotchas + how-to-verify, not literal diffs.
> Grounded in the brainstorming session 2026-07-23.

## Why now (time-sensitive)

Distillation is **paused at 268/620**. A spot-check of the firehose showed the `asset` field is
much messier than `BTC` vs `Bitcoin`: ~350 distinct labels, auto-caption **mishearings** the LLM
silently "corrects" (`Cardano→"Cards"`, `Cheniere→"Shener"`, `Fartcoin→"Path/Fatcoin"`,
`gap fill→"gadfield"`). The good news: the model already flags these incidentally in parens
(`'Cardano (Cards)'`). The risk: **silent mis-correction** — a misheard word laundered into a
plausible-but-wrong *valid* ticker that a downstream registry can never catch.

Fixing extraction is cheap **now** (re-`--force` 268 + fresh 352 = pay the replay once) and
expensive later (re-pay at 620, plus anything derived on top — 3.3 scores, 3.5 embeddings, promoted
vault notes — compounds on a cracked base). This unblocks resuming the 352 on the improved prompt.

## Design (approved)

Capture the "sounded like" provenance the model is already producing incidentally, as **one new
nullable field** — no richer nested `AssetRef` (that would turn `asset` from str→object and break
every `thesis.asset` reader; the living schema doesn't need that churn yet).

- `asset` — clean best-guess ticker (standard uppercase), held to tighter format by the prompt.
- **`asset_heard: str | None`** *(new)* — verbatim ASR phrasing, populated **only when the model
  corrected/guessed** (`"ethereal"`, `"Cards"`). Presence = the "I wasn't sure" flag. No new
  confidence field — thesis-level `confidence` already covers shaky calls.
- Recovery UX is then free: `asset` + `asset_heard` + existing `key_levels` (the price) → eyeball
  confirm. Real ticker validation is **read-time (Phase 3a / CoinGecko)**, not in-prompt — keeps the
  extraction call lean.

**Out of scope for 2.1** (logged as deferred, below): `key_levels` number-garble guarding,
CoinGecko/price cross-referencing, the read-time registry itself.

## Tasks (TDD: RED → GREEN per unit)

1. **Schema: add `asset_heard`** — `core/thesis.py`.
   - Add `asset_heard: str | None = None` to `_Extracted` and `Thesis`; thread through `build_thesis`.
   - Test (`core/tests/test_thesis.py`): field defaults `None`; round-trips when set; trade/macro
     invariants unchanged (discriminated union untouched).
   - *Consideration:* keep it optional forever — most calls won't set it. Tolerant readers ignore it.

2. **Flat schema: advertise the field to the model** — `distill/cli_backend.py`.
   - Add `asset_heard: {"type": "string"}` to `FLAT_THESIS_SCHEMA` properties. **Do NOT add to
     `required`** — the `--json-schema` strict subset would then force it on every call.
   - Test (`test_cli_backend.py`): schema includes `asset_heard`, `required` does not.
   - *Gotcha:* this is the load-bearing step — without it the strict path never surfaces the field,
     so the prompt instruction alone would silently no-op.

3. **Prompt: format + provenance instruction** — `distill/prompt.py`.
   - `_SYSTEM`: (a) emit a standard uppercase ticker in `asset`; (b) when the transcript term was
     phonetically off / ambiguous, put the raw heard form in `asset_heard` and lower `confidence`.
     Formalizes the incidental `(Cards)` behavior. **No ticker vocab list injected** (token bloat;
     validation is read-time).
   - Test (`test_prompt.py`): system prompt mentions `asset_heard` + the ticker-format rule.
   - *Consideration:* keep wording tight — it runs on all 620. One or two sentences, examples optional.

4. **Extract passthrough** — `distill/extract.py` (+ `test_extract.py`).
   - Verify a mocked response carrying `asset_heard` survives parse → Pydantic → `build_thesis`.
     Likely zero code change (generic passthrough); the test is the real deliverable.

5. **Re-distill run** — command, not code. `uv run distill-roster --force` (full 620: force-redistill
   268 + fresh 352). Verify: run summary, then re-run the firehose spot-check — `asset_heard` now
   populated on the known garbles (`Cards`/`Shener`/`Fatcoin`), and confirm no schema-validation
   regressions (still 0 trade-without-invalidation).
